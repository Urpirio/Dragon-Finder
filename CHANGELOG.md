## [0.0.0] - 2024-11-08

### Agregado
- Sistema de búsqueda de personajes de Dragon Ball
- Búsqueda en tiempo real con autocompletado
- Integración con Dragon Ball API
- Interfaz de usuario con React y Vite
- Estilos personalizados con LESS
- Filtro de búsqueda inteligente (hasta 6 caracteres)
- Esquemas de colores únicos por personaje
- Visualización detallada de información del personaje
- Soporte para diferentes razas y géneros
- Sistema de navegación con cierre de tarjetas

### Características
- Búsqueda insensible a mayúsculas/minúsculas
- Coincidencia exacta de nombres
- Búsqueda por prefijo
- Renderizado dinámico de resultados
- Integración con Boxicons

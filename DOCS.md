2. Sigue la [Guía de Inicio Rápido](QUICKSTART.md)
3. Explora la sección de [Uso](README.md#-uso)

1. Lee el [Código de Conducta](CODE_OF_CONDUCT.md)
2. Revisa la [Guía de Contribución](CONTRIBUTING.md)
3. Configura tu [Entorno de Desarrollo](CONTRIBUTING.md#-configuración-del-entorno-de-desarrollo)
4. Sigue el [Proceso de Desarrollo](CONTRIBUTING.md#-proceso-de-desarrollo)

### Entender el Código

1. Revisa la [Estructura del Proyecto](README.md#-estructura-del-proyecto)
2. Lee sobre las [Tecnologías Utilizadas](README.md#-tecnologías-utilizadas)
3. Explora las [Características del Código](README.md#-características-del-código)
4. Revisa los comentarios inline en los archivos fuente
